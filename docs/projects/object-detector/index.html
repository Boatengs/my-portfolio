PROJECT 08 / Computer Vision · Zero-Shot Detection

Open-Vocabulary Object Detector

A 232M-parameter Grounding DINO application that detects objects from natural-language prompts.

LIVE APPLICATION CAPTURE
01

The challenge

Move beyond fixed object classes by allowing users to describe what they want the model to locate in an image.

02

The approach

Built an interactive detection workflow around Grounding DINO with natural-language targets, confidence controls, and eight quick presets.

03

The outcome

A running Hugging Face demo supporting unlimited object classes through zero-shot, open-vocabulary detection.

04 / LIMITATION

What the project does not solve—yet.

The large model has meaningful latency and compute requirements, while prompt wording, crowded scenes, and small objects can affect detection quality.

05 / NEXT ITERATION

How I would move it forward.

Explore quantization and faster backbones, add video tracking and batch inference, and benchmark prompt robustness for edge deployment.

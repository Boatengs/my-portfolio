PROJECT 10 / LLM Evaluation · Medical AI

LLM Evaluation Framework

An interactive comparison of base Mistral 7B and a LoRA fine-tuned medical model.

LIVE APPLICATION CAPTURE
01

The challenge

Measure whether parameter-efficient medical fine-tuning produces consistent gains across clinically distinct question categories.

02

The approach

Evaluated base and fine-tuned responses across 20 questions and five medical domains using ROUGE comparisons and pairwise wins.

03

The outcome

Recorded a 17.8% ROUGE improvement and a 65% win rate for the LoRA fine-tuned model.

04 / LIMITATION

What the project does not solve—yet.

The current 20-question evaluation and ROUGE-based scoring are too small to capture clinical correctness, reasoning quality, safety, and nuanced failure modes.

05 / NEXT ITERATION

How I would move it forward.

Build a larger clinician-reviewed benchmark with factuality, safety, calibration, pairwise preference, and reproducible automated evaluation dashboards.

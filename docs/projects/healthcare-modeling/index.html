PROJECT 03 / Classification · Healthcare

Healthcare Resource Modeling

Comparative classification models for healthcare resource planning.

EXPLORE · MODEL · VALIDATE · COMMUNICATE
01

The challenge

Evaluate competing modeling strategies for a healthcare resource-allocation problem with many correlated features.

02

The approach

Developed Logistic Regression, Random Forest, and SVM baselines, then evaluated PCA-based dimensionality reduction in Scikit-learn.

03

The outcome

A transparent comparison of model behavior and tradeoffs designed to support informed resource decisions.

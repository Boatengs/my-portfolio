PROJECT 08 / Computer Vision · Zero-Shot Detection

Open-Vocabulary Object Detector

An interactive vision tool that lets a person describe an object in ordinary words and then asks the model to locate matching items in an uploaded image.

LIVE APPLICATION CAPTURE
01

Why this project matters

Traditional object detectors recognize only the categories selected during training. This project explored a more flexible question: can a user type what they want to find—without the application being rebuilt for every new object class?

02

What I built

I built a Gradio application around the pretrained Grounding DINO model, added natural-language targets, confidence controls, and quick prompts, and returned labeled boxes around matching regions in an uploaded image.

03

What it means

The working demo shows how open-vocabulary detection makes computer vision more adaptable. Users can search for many kinds of objects with words, although detection quality still depends on the prompt, scene complexity, and model limits.

04 / WHERE THIS WORK APPLIES

From project to practical use.

Open-vocabulary detection can support e-commerce cataloging, warehouse and inventory review, accessibility tools, safety monitoring, agriculture, wildlife research, media search, and rapid prototyping when fixed labels are too restrictive.

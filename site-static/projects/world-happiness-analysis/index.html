METHOD

One dataset.
Two deployments.

The original project remains a Streamlit application. This portfolio deployment is deliberately client-side: the browser requests the pinned CSV directly, normalizes the year-specific schemas, restores historical region labels, computes ranks and summary statistics, and renders Plotly charts without requiring a Python server.

  • No CSV upload step.
  • Source pinned to a specific upstream Git commit.
  • Same 2015–2019 analytical scope as the project app.
  • Regression uses 2015–2018 training rows and a 2019 holdout.
